## Finding the auto-join advertisers (the day-one unlock)

Awin's "soft membership" rule, quoted from their [publisher FAQs](https://help.awin.com/developers/docs/faqs-for-publishers):

> "Awin operate a 'soft membership' rule which applies to selected Advertisers
> who have 'auto-join' enabled for their affiliate approvals and have a valid
> Data Feed. **If a sale occurs via the use of this Data Feed you will be
> credited for this transaction.**"

So auto-join advertisers give you feed access *and* tracked commissions with no
approval wait. Two ways to find them:

1. **Link Builder → "Not Joined" section** — Awin: "you'll find a list of
   advertisers whose programmes you can join instantly."
2. **Feed List Download CSV** (better, machine-readable):
   `https://productdata.awin.com/datafeed/list/apikey/{APIKEY}`
   Returns `Advertiser ID, Advertiser Name, Primary Region, Membership Status,
   Feed ID, Feed Name, Language, Vertical, Last Imported, URL`. **Any row with
   `Membership Status = Not Joined` is soft-membership and already usable.**

⚠️ **The feed-list API key is a different key from the Publisher API key.** Get
it from `Toolbox → Links & Tools → Create-a-Feed` — it's embedded in any
generated feed URL.

## Feed build settings

**Choose Legacy, not Enhanced.** Enhanced (Google-format) feeds use
`image_link` / `additional_image_link` and have **no `aw_image_url` at all**, so
you lose the Awin-hosted fallback.

Columns to select: `merchant_image_url`, `aw_image_url`, `aw_thumb_url`, `ean`,
`mpn`, `brand_name`, `product_name`, `size`, `colour`, `search_price`,
`in_stock`, `aw_deep_link`, `aw_product_id`.

Start with `compression/none` — gzip downloads arrive with no filename or
extension (saved literally as `1`) and choke CSV readers.

**Image gotchas:**

- `aw_image_url` is capped at **200x200**, UK/IE/CA/US markets only. It's a
  signed proxy (`images2.productserve.com`, `k=` is a 40-char signature) so you
  **cannot bump `w=200` to get a bigger image** — you get a 403.
- Awin caches images for **30 days**, then re-fetches from the merchant CDN. If
  the merchant URL died meanwhile, the safety net expires.
- **When an image is missing, Awin returns a "noimage" PNG with HTTP 200, not a
  404.** Naive broken-image detection passes silently. Hash-check against it.
- `merchant_image_url` is full resolution but on the retailer's CDN — fetch it
  server-side with a browser User-Agent (some merchants block bare fetch UAs)
  and re-host.

**Refresh:** cadence is advertiser-controlled (daily up to 4x, weekly, or manual
uploads that go stale). Poll the `Last Imported` timestamp rather than
re-downloading blindly. Awin asks for a 10-120s delay past the top of the
minute, and ≤5 req/min on the REST API.

**Delisting has no signal** — products just vanish from the file. Diff each
refresh.

## Two landmines that will bite during implementation

### 1. German product titles will break the matcher

Douglas_DE and Flaconi are the two largest catalogs by an order of magnitude,
and both ship **German-language product titles**.

`scraper/src/backfill-affiliate-images.ts` currently matches on normalized
brand + name, with `CONCENTRATION_WORDS` stripping English terms (`eau`, `de`,
`parfum`, `toilette`, `homme`, `femme`, `men`, `women`). Against German titles
that heuristic collapses — and `FEED_COLUMNS` has **no `ean` mapping at all**.

**Fix before running the backfill:** add `ean` / `gtin` / `upc` to
`FEED_COLUMNS` and make EAN the primary match key, with brand+name fuzzy
matching as the fallback. Note that Awin explicitly does **not** validate EAN,
UPC or GTIN, so validate check digits and expect empties, `0`, `N/A`, and
leading-zero truncation from advertisers who exported via Excel.

### 2. "Without modification" is now confirmed from four directions

Escentual, Primor and Paco Perfumerias each independently prohibit altering
creative, on top of Awin clause 10.1's "without modification." That's four
advertisers plus the network terms all saying the same thing: **normalizing,
cropping or background-removing bottle images into a consistent grid is outside
what these programmes permit.** Tier 1 approval does not solve this. Decide
whether to design around raw merchant images or accept visual inconsistency.

## Application notes

Awin's [own list of rejection reasons](https://success.awin.com/s/article/Why-was-my-network-application-rejected?language=en_US) — note that **traffic volume is not on it**:

- Missing or inconsistent application information
- Name, address or website that cannot be verified
- Promotional space description lacks clarity or supporting content
- Verifiable proof of domain ownership not provided

Concretely for spritzofficial.app:

1. **Select promotional type "Content." Do NOT select "Search."** Premium brands
   ban trademark PPC bidding, and fragrance brands are exactly that type —
   selecting Search causes instant denials.
2. **Prove domain ownership.** Use an email on the spritzofficial.app domain and
   make sure WHOIS matches the name and address on the application.
3. Have a **Privacy Policy, Terms, and an Affiliate Disclosure** live before
   applying.
4. **Write the promotional space description as if it's the whole application** —
   it's the field Awin names directly. Pre-revenue is fine; vagueness is not.
5. No broken links or missing images on the site at application time.
6. **Fill out the Awin publisher profile immediately after approval** — network
   approval is not advertiser approval, and advertiser managers read that
   profile before approving you.

**Rejection is expensive:** application data is retained 60 days before you can
resubmit, and prior rejections may follow via device/email fingerprinting. The
£5 is refundable on rejection by request to compliance. Get it right first time.

New advertiser approvals take up to 1 hour to appear in Create-a-Feed.
